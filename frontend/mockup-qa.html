自由問答
哪些課程會教到 Python 程式設計？

根據課綱，全校有數門課程涵蓋 Python 程式設計，主要分布在資訊與資料分析領域：

  • 資料分析與決策：以 Python 進行資料清理、視覺化與統計建模
  • 資料科學導論：使用 Python 與 pandas、scikit-learn 實作機器學習基礎
  • 程式設計入門：從 Python 語法開始，建立程式邏輯基礎

其中「資料分析與決策」最適合非資訊背景學生入門。

你可能想問
哪一門適合零基礎？ 這些課要先修什麼？ 有英語授課的嗎？
那其中哪一門比較適合完全沒寫過程式的人？

對完全沒有程式經驗的學生，最推薦「程式設計入門」：

  • 零基礎友善：從變數、迴圈等最基本概念教起，不假設先備知識
  • 節奏較緩：課綱安排每週小作業循序漸進，期末才到專案

「資料分析與決策」雖也適合入門，但會同時要求統計概念，建議有基礎後再修。
